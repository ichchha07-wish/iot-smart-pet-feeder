# 🐾 IoT Smart Pet Feeder

An ESP32-based automated pet feeder with real-time 
cloud monitoring dashboard.

## ✨ Features
- 🕐 Scheduled auto food dispensing via servo motor
- 🐶 Ultrasonic sensor detects if pet is nearby
- ⚖️ Load cell measures food weight dispensed
- 📟 OLED display shows live status
- ☁️ Firebase cloud backend
- 📊 React + Vite dashboard for remote monitoring

## 🛠️ Tech Stack
- **Hardware:** ESP32, Servo Motor, Ultrasonic Sensor, 
  Load Cell, DS3231 RTC, OLED Display
- **Frontend:** React, Vite, Firebase
